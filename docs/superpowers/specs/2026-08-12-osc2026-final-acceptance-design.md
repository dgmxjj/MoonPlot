# MoonPlot OSC2026 最终验收补强设计

## 目标

针对组委会驳回意见，把 MoonPlot 从“可演示的图表渲染库”补强为“可复用、可验证、可复现实验的 MoonBit 数据可视化组件”。所有新增源码必须服务于公开 API、真实数据处理、渲染正确性或验收证据，不以空泛增加行数为目标。

## 驳回意见映射

| 驳回项 | 交付证据 |

## 功能范围

### 1. 数据与统计层

新增 `src/data` 与 `src/stats` 包：

- CSV 记录解析：支持表头、引号字段、逗号、空值和行级错误报告；不把文件 IO 混入核心库。
- `NumericSeries`：稳定保存名称与数值，支持清洗、切片、求和、均值、方差、最小/最大值、分位数和归一化。
- 描述性统计：最小值、最大值、均值、中位数、标准差、有效样本数、缺失数和异常值计数。
- 直方图与分位数区间：用于把真实基准数据转换成柱状图/散点图输入。
- 滑动窗口聚合和相关系数：用于性能趋势、传感器趋势等实际场景，明确小样本和常数序列行为。

### 2. 图表与布局层

- 新增 `ChartSpec`/数据集辅助 API，使标题、数据系列、统计摘要和后端选择可以按声明顺序组装。
- 新增可复用 `PanelGrid`，对行列数、间距、极小尺寸和图例占位进行确定性计算。
- 为 Line/Bar/Scatter 补充配置方法、空输入行为、负值基线和数据范围辅助函数。
- 保持现有 API 向后兼容；新能力只增加公开入口，不重命名已有类型或方法。

### 3. 基准与示例

- `examples/data/throughput.csv`、`examples/data/temperature.csv` 等小型、可审计、可纳入版本控制的真实格式数据。
- `examples/benchmark_summary`：读取内嵌 CSV 字符串，输出统计摘要与 SVG，保证不依赖本地文件系统。
- `docs/BENCHMARKS.md`：记录数据来源、字段含义、预期统计结果、运行命令和边界样本。

## 测试策略

- 先写失败测试，再实现对应 API；每个新增包包含黑盒测试。
- 统计测试覆盖空序列、单元素、重复值、负值、NaN/无穷值替代输入、常数序列和非整除窗口。
- CSV 测试覆盖引号、逗号、空字段、换行、列数不一致和空文件。
- 布局测试覆盖 0 行/列、极小画布、过大间距和多图例。
- 渲染测试检查 SVG/Canvas 的关键命令、转义字符和负值矩形，不依赖脆弱的完整字符串快照。
- CI 使用 `moon check/build/test --target all --deny-warn`，并检查格式和生成的 `.mbti` 无漂移。

## 文档与合规

- README 明确当前版本、工具链建议、安装、运行、输出、API、范围、非目标和故障排查。
- `docs/API.md`、`docs/ARCHITECTURE.md`、`docs/BENCHMARKS.md` 和 `docs/REFERENCES.md` 相互链接。
- 依赖仅使用 MoonBit 标准库；参考项目只用于概念与 API 组织，许可证和来源明确，不复制第三方源码。
- 所有提交使用仓库创建者单一身份；不保留平台凭据、临时生成文件或外部平台截图作为仓库内容。

## 验收完成标准

1. 现有 17 条历史提交的唯一作者身份保持不变，新提交也使用同一身份。
2. 三平台 CI 文件包含 `moon build`，并有可靠的工具链/依赖安装步骤。
3. 真实库代码达到约 3,800–4,300 行，增量来自数据、统计、布局、渲染和测试支持的实际实现。
4. `moon fmt --check`、`moon check/test/build --target all --deny-warn` 和接口漂移检查通过；若本机缺少 native 编译器，必须在 CI 中验证 native 目标。
5. README 与示例命令在干净环境中可复现，基准结果与文档一致。
6. 最终自查报告逐项对应组委会驳回意见，并记录当前未覆盖的非目标能力。

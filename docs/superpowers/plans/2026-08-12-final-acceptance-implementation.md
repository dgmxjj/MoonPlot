# MoonPlot OSC2026 最终验收实施计划

> **执行约束：** 每个功能批次先添加能表达验收行为的黑盒测试，确认测试因缺少 API 或错误行为失败，再实现最小功能，最后运行格式、检查、构建和测试。

## 1. 建立当前基线

1. 记录当前分支、远程默认分支、唯一作者、跟踪文件和有效 `.mbt` 行数。
2. 保存现有 `moon fmt --check`、`moon check/test --target wasm,wasm-gc,js` 结果，作为回归基线。
3. 确认新增包的依赖只来自项目内部和 MoonBit 标准库，避免引入新的许可证风险。

## 2. 数据解析与数值序列

1. 新建 `src/data` package 及黑盒测试。
2. 先测试 CSV 解析：表头、引号字段、空值、列数错误、空输入和错误行号。
3. 实现无文件 IO 的 `CsvTable`、`CsvRowError` 与可复现字符串解析器。
4. 新建 `src/stats` package 及黑盒测试。
5. 先测试 `NumericSeries` 的清洗、描述性统计、分位数、归一化、直方图、滑动窗口和相关系数。
6. 实现稳定的数值 API，明确空样本、常数序列、非法分箱数和非整除窗口的行为。

## 3. 图表与布局能力

1. 先为现有 Line/Bar/Scatter 的颜色、宽度、半径、样式和数据范围辅助方法补充失败测试。
2. 实现配置方法，并修复负值、零值和空数组的确定性行为。
3. 新建可复用的 `PanelGrid`，先测试正常网格、边距、间距、极小画布与非法行列数。
4. 实现面板边界计算，与 `ChartLayout` 的绘图区语义保持一致。
5. 为 SVG/Canvas 增加输出摘要或命令计数辅助方法，测试关键元素、特殊字符转义和空多边形。

## 4. 真实基准与可执行示例

1. 加入小型、可审计的 CSV 基准文件，记录来源、字段含义、样本数和预期统计摘要。
2. 新建 `examples/benchmark_summary`，使用内嵌/仓库数据生成统计文本和 SVG，避免示例依赖未说明的外部服务。
3. 增加 `docs/BENCHMARKS.md`，给出 Linux/macOS/PowerShell 命令和预期结果。
4. 修订 README：安装、版本、API、示例、基准、边界契约、故障排查、许可和参考范围全部可跳转。

## 5. 合规与 CI

1. 检查 `moon.mod`、LICENSE、README、REFERENCES 和依赖清单的一致性。
2. 将 CI 的工具链版本、平台依赖、`moon build`、全目标测试、格式和 `.mbti` 漂移检查写清楚。
3. 增加贡献/开发说明，明确提交身份要求、生成文件策略和本地复现方法；不写入账号、密码、令牌或平台内部凭据。

## 6. 验证与最终审计

1. 运行 `moon fmt --check`、`moon check --target all --deny-warn`、`moon build --target all --deny-warn`、`moon test --target all --deny-warn`。
2. 运行 `moon info` 并确认生成的 `.mbti` 无漂移。
3. 统计有效库代码、测试代码、示例代码和基准数据，不把 `_build` 或生成文件计入有效规模。
4. 复核提交历史、作者、远程默认分支、GitHub/GitLink 同步状态、许可证和仓库敏感信息。
5. 逐项对照驳回意见形成最终验收清单，只有所有命令和证据真实通过后才声明完成。
